Train new models here, and choose which one scores your orders. Training one does not switch it on — you do that separately, with Use this one.

Why won't it just use the newest model?

Because newer is not the same as better. Retraining always gives you a new model, and sometimes a worse one. So before swapping, we compare the new model against the one already in use on {{ metric }}, and refuse the swap if it has got worse. Force overrides that, when you know something the comparison does not.

What do these four scores mean?

All four run from 0 to 1, higher is better. ROC AUC and Avg precision ask how well the model sorts orders — whether the ones that end up late come out near the top. That is what matters here, because you work down a list. F1 and Accuracy ask how often it labels a single order correctly, which depends on where you put the cut-off. What does it train on?

The dataset file sitting on this server. Nothing anybody enters through the order form ever reaches the training data, which is why an ordinary account cannot poison the model by feeding it made-up orders.
