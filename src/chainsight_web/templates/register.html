Why are there no password rules?

Length is the part that costs an attacker time. Rules about capitals and symbols push people towards shorter passwords they can remember, which is the wrong trade.

How do I get an administrator account?

Not from this form — the administrator role is not a field on it and cannot be asked for. Somebody with access to the server grants it, by running python -m chainsight_web init there. An account you can promote yourself into is not a role, it is a checkbox.
