Costs

Tell ChainSight what a late delivery costs you, and what it costs to prevent one. These numbers decide which orders get flagged and how they are ranked — the model itself knows nothing about money.

Where did these numbers come from?

From somebody's judgement, not from the data. The dataset records no intervention, no penalty and no customer reaction, so there is nothing here to learn them from. They are editable fields rather than constants buried in the code precisely so that disagreeing with them is a conversation about your business instead of a code change. Each one is argued here.
